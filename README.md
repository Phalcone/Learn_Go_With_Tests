# Learn Go with Tests

This repository documents my journey learning Go by following [Learn Go with Tests](https://quii.gitbook.io/learn-go-with-tests).

My goal is to build a strong foundation in Go while learning test-driven development (TDD), writing idiomatic code, and understanding good software engineering practices.

## What I'm learning

- Go fundamentals and language features
- Test-driven development: Red, Green, Refactor
- Writing clear, maintainable tests
- Refactoring with confidence
- Git and version control best practices
- Writing idiomatic Go

## How I'm learning

I'm following the book chapter by chapter and implementing the exercises myself. I'm using tests to guide development, committing working milestones, and refining my code as my understanding improves.

This repository represents my learning process, not a finished library or production application.
